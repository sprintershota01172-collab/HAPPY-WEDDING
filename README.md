# Happy Wedding ✿

**ふたりで楽しく進める、スマホ向け結婚式準備アプリ。**

初期挙式日: **2027年2月20日**（変更可能）

## アプリを開く

GitHub Pages を有効化すると以下で開けます。

**https://sprintershota01172-collab.github.io/HAPPY-WEDDING/**

初回は **挙式日 → 自分の役割** の2ステップです。iPhoneのSafariから「共有」→「ホーム画面に追加」でアプリ風に使えます。

> GitHub Pages が未設定のリポジトリでは、上記URLは有効ではありません。リポジトリの Settings → Pages → Build and deployment → Source で **GitHub Actions** を選択してください。Actionsでデプロイが成功すると公開されます。

## 画面

| 画面 | 機能 |
|---|---|
| ホーム | 挙式までの日数、全体進捗、支払い、ひとことコメント |
| やること | 自分・役割別タスク、進捗、サブタスク、写真・URL、半年前〜式後テンプレ |
| お金 | 全体と項目別予算、見積・契約・支払済・残額、支払期限、ご祝儀、予算バー |
| ゲスト | 出欠、住所、親族・友人・職場、アレルギー、引出物・車代・宿泊、招待状送付、席次表 |
| その他 | 当日進行、業者・打ち合わせ、アイデア、持ち物、お礼、役割、共有、JSON/CSV、設定 |

ローカル環境で `index.html` を直接開くとService Workerや一部機能は動作しません。PagesなどのHTTPSホスト、またはlocalhostで実行してください。

## ローカル保存とオフライン

- 入力したデータは端末の `localStorage` に自動保存
- Service Workerがアプリ画面のファイルをキャッシュしてオフラインでも開けるようにする
- JSONバックアップ、JSON復元、項目別CSV書き出し対応
- 写真は小さくリサイズして保存（画像が増えた場合は保存容量制限があります）
- ブラウザのプライベートモード、サイトデータ削除、iOSの保存領域の違いで消失する可能性があるため、定期的にバックアップを取ってください

## ふたりの端末間でリアルタイム同期するには

**Firebase設定が必要です。** Firebaseの認証やデータベースをこちらで自動作成するものではありません。設定を済ませるまで端末間の同期はありません。

1. [Firebase Console](https://console.firebase.google.com/) でプロジェクトを作成
2. Authentication → Sign-in method で **Anonymous** を有効化
3. Cloud Firestore データベースを作成し、このリポジトリの `firestore.rules` をFirestoreルールに貼り付けて公開
4. プロジェクトにWebアプリを追加し、Firebaseの設定値から `apiKey`・`projectId`・`appId`・`authDomain` を控える
5. アプリの「その他 → ふたりで共有」に入力して、「新しい共有コードを発行」→「保存して接続」
6. もう一方の端末にも同じFirebase設定と**同じ共有コード**を入力し、保存・接続

共有コードは暗号学的乱数で生成した48文字の招待キーです。**コードを知る人はそのルームのデータを読み書きできる**仕組みです。コードを他人に公開せず、機密データを扱う場合は、より強固なユーザー別アクセス制御が必要です。Firebaseプロジェクトの利用状況・費用・ルールは所有者側で管理してください。

同期はドキュメント単位の上書き方式です。**同じ項目を二人が同時編集した場合、最後にクラウドへ保存された内容が優先**されます。通信切断中は端末に保存し、クラウド設定済みであれば変更を後で送信します。端末を変えるときや共有を切り替えるときはデータのバックアップを取ってください。大容量写真の同期にはFirestoreのドキュメント制限があるため、大きな画像を直接保存しないよう制限しています。

## 通知

期限が3日以内または超過したタスク・支払予定を、アプリ起動・復帰時に知らせます。ブラウザが対応し通知許可された場合のみ通知を表示します。**閉じている間のプッシュ通知は未実装**です。

## 仕様補足

- 項目ごとの「支払済み」は、登録した支払予定のうち完了済み金額と「予定にない支払済額」の合計です。同じ費用を両方に入れると二重計上します。
- 最終持ち出し見込み = max(0, 契約額または見積の合計 − ご祝儀・支援金の登録額)
- 未契約の項目は見積額、契約済みの項目は契約額を優先します。実際の請求総額を保証するものではありません。
- 席次表はタップ操作とドラッグ＆ドロップに対応します。
- 役割は誰でも追加・編集でき、初期値は新郎／新婦／両家の親／受付係／司会・友人幹事／プランナーです。
